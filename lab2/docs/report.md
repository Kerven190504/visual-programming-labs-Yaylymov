# Отчет по Лабораторной работе №2. Введение в Node-RED

**Выполнил:** Кервен Яйлымов

## Цель работы
Освоить базовые принципы low-code программирования, маршрутизации сообщений и интеграции систем с помощью платформы Node-RED.

## Выполненные задачи (Базовый уровень)
1. **Установка Node-RED:** Выполнена локальная установка через `npm` (вместо Docker) с развертыванием локального сервера.
2. **Базовые узлы (2.1 - 2.12):** 
   - Изучены и применены узлы `Inject`, `Debug`, `Function`, `Switch`, `Change`, `Template`.
   - Настроен HTTP-запрос к стороннему REST API.
   - Настроен обмен сообщениями через публичный брокер MQTT (HiveMQ).
   - Создан собственный HTTP API endpoint, возвращающий JSON.
   - Реализованы чтение и запись данных в локальный текстовый файл.
   - Настроен перехват системных ошибок с помощью узла `Catch`.
   - Опробованы механизмы контроля скорости потока (`Delay`) и реле времени (`Trigger`).
3. **Графический интерфейс:** Установлен модуль `node-red-dashboard`, создана панель управления с ползунком (`slider`), индикатором (`gauge`) и самописным графиком (`chart`).

## Достижения
* **Локальная установка среды:** Успешно выполнена установка и запуск Node-RED глобально через пакетный менеджер npm (альтернатива Docker).

## Вывод
В ходе лабораторной работы освоена визуальная среда Node-RED. Практика показала, что компонентный подход позволяет быстро создавать API, работать с протоколами HTTP и MQTT, а также строить интерактивные дашборды с минимальным написанием кода на JavaScript.
