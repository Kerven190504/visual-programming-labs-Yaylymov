# Отчёт по лабораторной работе №3. Bubble

## 1. Краткое описание выполненного
В ходе лабораторной работы было создано веб-приложение «Учёт расходов» на базе no-code платформы Bubble. Каркас приложения сгенерирован с помощью встроенного AI. Затем был вручную доработан пользовательский интерфейс (UI): изменены заголовки, внедрена глобальная переменная цвета, настроены стили кнопок и добавлен сторонний компонент. Спроектирована база данных (сущность `Расход`) с настройкой Privacy Rules. Реализована логика CRUD: добавление новых записей через форму и удаление записей из списка (Repeating Group) с помощью Workflows.

## 5. Освоенные элементы и Workflows
* **Элементы UI:** Text, Button, Input, Dropdown, Repeating Group (для вывода списка базы данных), SliderInput.
* **База данных:** Создание Data Type (`Расход`), настройка полей, управление записями через вкладку App Data, настройка Privacy Rules (фильтрация по `Current User`).
* **Workflows:** 
  * `Create a new thing` (Добавление расхода с привязкой полей ввода к базе).
  * `Delete thing` (Удаление записи `Current cell's Расход` из списка).
  * `Reset relevant inputs` (Автоматическая очистка полей после создания).
* **Дизайн:** Глобальные переменные (Global Variables - `primary-color`), создание и применение кастомных стилей.
