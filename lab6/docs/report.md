# Отчет по лабораторной работе №6 (Kodular)

## 1. Базовое задание
Реализовано базовое мобильное приложение «Приветствие».
- Разработан дизайн экрана `Screen1` с текстовым полем, кнопкой и текстовыми метками.
- На экране присутствует обязательная метка с фамилией (Yaylymov).
- Настроена логика (Blocks): при нажатии на кнопку проверяется пустота поля ввода (`if/else`). Если пусто — выводится предупреждение «Введите имя!», иначе формируется приветствие через блок `join` («Привет, <имя>!»).

## 2. Ссылка на проект
Файл исходного кода проекта экспортирован и находится в репозитории: `lab6/exports/lab6-Yaylymov.aia`

## 3. Использованные AI-промпты
- "Где найти блок для проверки пустого текста (кавычки) в Kodular?"
- "Как вставить блок if внутрь события Click?"
- "Как соединить текст и переменную с помощью блока join?"

## 4. Освоенные компоненты и блоки
- **Компоненты UI:** Label, TextBox (использование свойства Hint), Button.
- **Блоки логики:** `when Button.Click`, `if/then/else`, математическое равенство `=`, объединение строк `join`, изменение текста `set Label.Text to`, чтение текста `TextBox.Text`.

## 5. Ограничения бесплатного тарифа
При работе на бесплатном тарифе Kodular существуют следующие лимиты:
- До 10 проектов на одном аккаунте;
- До 10 МБ загружаемых ассетов (картинок, звуков);
- Использование не более 5 расширений (extensions).
