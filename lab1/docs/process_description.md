# Бизнес-процесс: Оплата коммунальных услуг через мобильный банкинг

**Участники (роли):**
1. Пользователь (Плательщик)
2. Мобильное приложение банка
3. Единое расчетное пространство (ЕРИП / Биллинговый шлюз)
4. Поставщик коммунальных услуг (ЖКХ)

**Описание процесса:**
1. Пользователь выполняет авторизацию в мобильном приложении банка и открывает раздел платежей.
2. Пользователь выбирает категорию «Коммунальные платежи», указывает поставщика услуг и вводит номер лицевого счета.
3. Мобильное приложение отправляет запрос в расчетную систему (ЕРИП) для валидации номера счета и получения актуальной задолженности.
4. Расчетная система возвращает данные: если лицевой счет не найден, система выводит сообщение об ошибке, и процесс завершается.
5. При корректном номере счета приложение отображает сумму к оплате, показания счетчиков и период начисления.
6. Пользователь сверяет данные и выбирает банковскую карту для списания средств.
7. Приложение проверяет доступный баланс: если средств недостаточно, пользователю предлагается сменить карту или прервать операцию.
8. При наличии средств банк блокирует требуемую сумму на счете и запрашивает подтверждение через SMS/биометрию.
9. После подтверждения запускаются параллельные действия: банк списывает деньги и формирует фискальный чек, а расчетная система одновременно регистрирует закрытие начисления и уведомляет поставщика ЖКХ.
10. Приложение отображает статус «Платеж успешно совершен» и предлагает отправить электронный чек на почту.
